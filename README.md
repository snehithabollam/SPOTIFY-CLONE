# 🎵 Spotify Clone

A responsive Spotify Clone built using React and Vite.

## 🚀 Features

- 🎵 Browse music
- 🔍 Search songs
- 🎧 Music player interface
- ❤️ Like/favorite songs
- 📱 Responsive design
- 🎨 Spotify-inspired UI

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
